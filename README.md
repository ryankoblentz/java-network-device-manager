# Network Device Manager

A command-line Java application created as my final project
for an introductory Java programming course.

The program allows users to:

- Add network devices with a name and IP address
- Track whether devices are online or offline
- View all stored devices
- Search for a device by name
- Update a device's status
- Validate user input

## Concepts Used

- Java arrays
- Methods
- Loops
- Conditional statements
- Switch statements
- Scanner input
- Input validation
